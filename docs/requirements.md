# 要件

## 目的と利用者

水害時の痕跡調査、事前調査、現地踏査を行う研究者・学生・技術者が、公式地理空間情報を一般的なPC・タブレット・スマートフォンのブラウザーで比較できるようにする。

## Version 0.1の機能要件

- 1・2・4個のOpenLayers Mapが同じViewを共有し、中心、解像度、ズーム、回転を同期する。
- 携帯電話では最大2画面とし、4画面指定は先頭2画面へ縮退する。
- 各ペインは背景地図、複数の重畳レイヤー、透明度、凡例を独立して保持する。
- 内蔵13レイヤー、5プリセット、常時確認可能な出典を提供する。
- ボタン操作時だけ現在地を取得し、マーカーと精度円を全画面へ表示する。
- 中心の緯度・経度・ズームと、取得可能な国土地理院DEM標高を表示する。
- 調査ピンをlocalStorageへ保存し、CRUDとKML・GeoJSON出力に対応する。
- EPSG:4326のローカルKML・GeoJSONを3857へ変換して表示し、4326で出力する。
- 表示状態だけをhash URLへ保存し、個人・非公開データを含めない。
- 一部の外部タイル・DEMが失敗しても、他の地図とローカルデータ操作を継続できる。

## 非機能要件

- GitHub Pages上の静的ファイルだけで完結し、サブパスで動作する。
- 主要操作はキーボード利用可能、明確なフォーカス表示、可能な限り44px以上とする。
- 移動中のReact更新を避け、moveendとデバウンスで中心・URL・DEMを更新する。
- `npm run check` と外部配信に依存しないPlaywright E2Eを品質ゲートとする。

## 禁止事項

独自バックエンド、データベース、認証、秘密情報、アクセス解析、広告、大量タイル保存、非公開API、スクレイピング、無制限CORSプロキシを追加しない。全国河川データ、KMZ、外部URLからのGIS読込みもVersion 0.1には含めない。
