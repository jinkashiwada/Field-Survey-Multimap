# ロードマップ

## Version 0.1（本リポジトリ）

同期1・2・4画面、公式ラスタレイヤー、プリセット、現在地、DEM中心標高、localStorageピン、ローカルKML・GeoJSON、hash共有、GitHub Pages公開を提供する。追加機能として、低ズーム衛星モザイクへ接続する全国最新写真、DEM10Bの明示操作型レンジ再配色、試験公開ベクトルの主要道路・鉄道・河川・等高線、河川名ホバー、地点コンテキストメニュー、座標・ローカル地物検索を含む。

## 次に優先する改善

1. 実機iPhone・iPad・Androidでレイヤーボトムシート、ファイル選択、位置権限、Canvas DEMを確認し、解析用色別標高と等高線の発熱・バッテリー消費を固定配色背景と比較する。
2. OpenLayers/KMLの相互運用サンプルを増やし、スタイル・ExtendedDataを含む実データで検証する。
3. バンドルをレイヤー設定・GIS機能単位に遅延読込みし、初期JavaScript容量を減らす。
4. 公式配布の河川W05を小地域へ抽出・簡略化する再現可能な変換手順を別途検討する。
5. 自動アクセシビリティ検査とSafari/Firefox向けE2E範囲を拡張する。
6. 全国住所・河川名検索は、公式の軽量な索引または許諾済み地域別静的データを選定してから追加する。

## 公式仕様確認後に検討

- 公式観測所位置データを出典・取得日付きの地域別静的GeoJSONとして配布する。
- 気象庁アメダス観測所と国土交通省水位観測所の地点メタデータを、移設・廃止・更新手順を含む静的データとして提供できるか再監査する。
- 公式・安定・CORS対応・再配布可能なAPI／タイル仕様が公開された場合に限り、水位・雨量・XRAIN等を実験機能として追加する。
- 利用者指定の外部KML・GeoJSON URL読込みは、CORS、許可ドメイン、サイズ制限、プライバシーを設計して追加する。無制限プロキシは作らない。
- Googleマイマップは、利用者が登録した共有URLを別タブで開く導線と、公開地図だけの任意iframe表示を検討する。編集は公式My Maps画面へ遷移し、KMLで相互交換する。非公開APIの利用、Google認証の内蔵、APIキー必須のMaps Embed APIは採用しない。
