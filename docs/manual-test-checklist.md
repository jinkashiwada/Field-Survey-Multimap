# 手動テストチェックリスト

## 起動とレイアウト

- [ ] `npm ci`、`npm run check`、`npm run test:e2e`、`npm run build` が成功する
- [ ] Windows/macOSのChrome・Edge・Firefox・Safariで初期2画面が表示され、ドラッグ・ズーム・回転が同期する
- [ ] 1画面、横長左右2画面、縦長上下2画面、1024×700以上の4画面へ切り替わる
- [ ] 狭い画面では4画面ボタンが無効で、4画面hash・プリセットが説明付き2画面へ縮退する
- [ ] レイアウト変更・画面回転後にタイルがペイン全面へ再配置される
- [ ] iPhone 16e相当幅でツールバーの文字が折り返されず、横スクロールで1行の高さを保つ
- [ ] アプリ名の帯と各ペイン上部の帯が表示されず、地図面積が確保される

## レイヤーとプリセット

- [ ] 必須13レイヤーと追加5レイヤーを選択でき、ペインごとの背景・複数重畳・透明度が他ペインへ影響しない
- [ ] モバイルのレイヤー設定を下端までスクロールしても、上部の「閉じる」が常に操作できる
- [ ] PCで画面1のレイヤーを開いた後に画面2を開くと、画面1が閉じ、常に1パネルだけ表示される
- [ ] 全国最新写真がZL2～18で表示され、ZL14未満は衛星モザイクである旨と追加出典を確認できる
- [ ] 解析用色別標高で手動レンジと常設の「表示範囲から配色レンジを推定」が動き、レンジがhashから復元される
- [ ] 自動推定を有効にするとmoveend後だけ16地点を取得し、設定がhashから復元される
- [ ] 4画面で複数ペインの自動推定を有効にしても、一回のmoveendで標本取得がペイン数分重複しない
- [ ] 初期表示、各プリセット、画面追加時に主要道路、鉄道、河川中心線、等高線が有効で、試験公開表示と出典を確認できる
- [ ] 河川中心線がZL6未満では非表示、ZL6～7では一般化線の実線、ZL8以上では大・中河川の破線ガイドと詳細線・水域の重ね合わせになる
- [ ] 同じ主要河川をZL7からZL14まで拡大しても破線ガイドが消えず、詳細線が広域線を埋め尽くさない
- [ ] 河川名注記へマウスを重ねると名称が表示され、マウス移動で地図全体が再描画され続けない
- [ ] 5プリセットのペイン構成が仕様どおりである
- [ ] 地図Attribution、凡例、レイヤー詳細、設定・出典を確認できる
- [ ] 「観測施設」を開くと現在中心・ズームを含む川の防災情報リンクが表示され、水位計・危機管理型水位計・河川監視カメラの説明がある
- [ ] 観測施設リンクを開く前には外部通信せず、リンクURLにピン・現在地・GIS地物が含まれない
- [ ] タイル通信をオフラインにしても画面数変更、ピン、ファイル操作が可能で、同一エラーが連続表示されない

## 現在地・中心・標高

- [ ] 現在地ボタンを押すまで権限要求されず、押すと全画面へ位置と精度円が表示される
- [ ] 拒否・タイムアウト・取得不能・非対応を日本語表示し、watchPositionが使われていない
- [ ] 中心十字が全画面にあり、緯度経度6桁・ズームがmoveend後に更新される
- [ ] DEMが得られる地点は値・DEM種別、海上やオフラインでは「取得不可」を表示する

## ピン・GIS

- [ ] 4種のピンを中心へ追加し、移動・編集・削除・確認付き全削除ができる
- [ ] 再読込み後もピンが残り、壊したlocalStorageでもアプリが起動する
- [ ] Point、MultiPoint、LineString、MultiLineString、Polygon、MultiPolygonのKML・GeoJSONを読める
- [ ] ドラッグ＆ドロップ、件数表示、利用者操作による全地物fitが動く
- [ ] 20 MB超・50,000地物超・不正・KMZを個別拒否して既読データを失わない
- [ ] 日本語名と座標を保ったKML・GeoJSONを出力し、アプリへ再読込みできる
- [ ] 河川LineStringが青色で、name／riverName／河川名を選択表示できる
- [ ] 右クリック／長押し位置からピンを追加し、中心移動、座標コピー、外部地図リンクを実行できる
- [ ] 一本指の長押しだけが地点操作を開き、二本指のピンチ・タップでは開かない
- [ ] 座標、ピン名、読込みGIS地物名を検索でき、不正座標を安全に拒否する

## URL・アクセシビリティ・公開

- [ ] hashを別タブで開くと中心、ズーム、回転、レイアウト、全ペインのレイヤー・透明度が復元される
- [ ] 「表示URLをコピー」と「このピンを共有」が`#s=1.`形式の圧縮URLを作り、従来の`#v=1&...`より短い
- [ ] 圧縮URLを別タブ・QRコード経由で開くと同じ表示を復元し、従来の非圧縮URLも開ける
- [ ] 通常の表示URLに現在地マーカー、ピン、KML・GeoJSONの属性が含まれない（受信ピン表示中も同様）
- [ ] 「このピンを共有」で選択した1件だけ共有し、メモの既定オフ／任意オンを確認する
- [ ] 別ブラウザーでピン付きURLを開くと対象中心・全ペインの設定が復元され、選択肢の帯を出さず自分のピンへ自動保存される
- [ ] 既存ピンを残したまま1件追加され、直後の再読込み・同じQRコードの再読取りでも重複しない
- [ ] 不正JSON・過大URL・範囲外座標は日本語通知となり地図操作を継続できる
- [ ] iPhone幅で共有ダイアログをスクロール・閉じる・URL手動コピーでき、受信quadは2画面へ縮退し、共有ピンの選択肢が地図を占有しない
- [ ] Clipboard API拒否時に選択可能な読取り専用URLダイアログが出る
- [ ] Tab・Shift+Tab・Enter・Spaceで主要操作が可能で、フォーカスが見える
- [ ] iPhone安全領域、44px操作対象、モバイルのレイヤーボトムシートを確認する
- [ ] 通常リポジトリの `/<repo>/`、`username.github.io` の `/`、独自ドメイン用 `/` でアセットが404にならない

## 性能・電池消費

- [ ] 解析用色別標高を表示したままpan・zoomし、処理が新規タイル受信時だけで操作中に継続的な高負荷にならない
- [ ] レンジを連続変更しても保持するSourceキャッシュが8レンジを超えて増え続けない
- [ ] 等高線オフ／オンを比較し、実機で操作不能な遅延・継続的な発熱・異常な電池消費がない
- [ ] 古い端末で負荷を感じた場合、自動推定をオフにし、固定「色別標高図」と等高線オフへ戻す案内を確認できる
