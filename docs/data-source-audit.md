# データソース監査

調査日：2026-09-02。AはGitHub Pagesから直接使える公式・安定公開タイル/API、Bは公式配布物を事前変換した静的データなら利用可能、CはVersion 0.1で必要な公開仕様・安定性・ブラウザー利用条件を確認できず見送る区分である。公式画面が閲覧可能であることだけを、機械利用可能な公開APIの根拠にはしない。

## 河川・観測・リアルタイム候補

| 対象 | 区分 | 公式候補・形式 | ライセンス・容量・変換判断 | Version 0.1判断 |
|---|---|---|---|---|
| 河川ライン | B | 国土数値情報「河川」W05。GML／シェープファイル等のダウンロード | [国土数値情報利用約款](https://nlftp.mlit.go.jp/ksj/other/agreement.html)と各メタデータを確認する。全国一括は容量・描画負荷が大きく、地域抽出、簡略化、GeoJSON化が必要 | 同梱しない。利用者のKML/GeoJSON読込みを最低条件として実装 |
| 水位観測所位置 | B（候補） | 国土交通省の水文水質データベース等で公式地点情報を取得できる候補 | 全国地点の安定したブラウザーAPIとしては採用せず、正式な一括配布物・利用条件を再確認後に静的GeoJSON化する | 同梱しない |
| 雨量観測所位置 | B（候補） | 国土交通省の水文水質データベース等の公式地点情報候補 | 水位観測所と同様。取得日、項目定義、座標系、利用条件を記録して事前変換が必要 | 同梱しない |
| リアルタイム水位 | C | 「川の防災情報」の公式画面は存在するが、Version 0.1実装の根拠にできる安定した公開ブラウザーAPI仕様を確認していない | 画面HTML・内部通信の解析、スクレイピング、CORS回避プロキシが必要になる方式は禁止 | 見送り |
| リアルタイム雨量 | C | 同上 | 公開画面を機械APIと推定しない。更新間隔・欠測・再配布条件も正式仕様が必要 | 見送り |
| 雨量コンター・XRAIN | C | 国土交通省の公式閲覧サービス・配信はあるが、Version 0.1で直接採用できる恒久URL、CORS、利用条件を公開仕様として確定していない | 内部タイルURLの逆解析は行わない。公式仕様が確認できればAとして再監査する | 見送り |
| 累積雨量コンター | C | 公式画面上の表示候補 | 公開仕様・期間定義・欠測表現・二次利用条件を確認できる直接APIを採用根拠として確定していない | 見送り |

## 静的河川データを将来追加する条件

出典URL、データ版・取得日、利用条件、対象地域、元座標系、変換コマンド、簡略化許容誤差、元容量と配布容量を記録する。全国データを単一GeoJSONで置かず、流域・都道府県等に分割し、必要時だけ読み込む。公式ベクトルタイルを追加する場合も、公開仕様・安定性・出典・CORSを再確認し、実験版として隔離する。
