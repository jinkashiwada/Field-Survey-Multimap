# データソース監査

調査日：2026-09-04。AはGitHub Pagesから直接使える公式・安定公開タイル/API、Bは公式配布物を事前変換した静的データなら利用可能、CはVersion 0.1で必要な公開仕様・安定性・ブラウザー利用条件を確認できず見送る区分である。公式画面が閲覧可能であることだけを、機械利用可能な公開APIの根拠にはしない。

## 公式試験公開ベクトル

国土地理院の[地理院地図Vector（仮称）提供実験](https://maps.gsi.go.jp/development/vt_expt.html)が公開するMVTを利用する。公式公開でブラウザーから直接取得できるが、安定版ではなく仕様変更・提供終了の可能性があるため、安定公開を条件とする通常のAとは区別して「A（試験）」とする。道路・鉄道・河川・等高線は初期表示とプリセットで既定オンとし、取得失敗してもアプリ本体を継続する。

| 情報 | 区分 | 提供形式・条件 | Version 0.1 |
|---|---|---|---|
| 高速道路・国道、鉄道、河川中心線・名称、水域、等高線 | A（試験） | `experimental_bvmap` MVT、ZL4～16（河川UIはZL6～16、等高線UIはZL8～16）。河川はZL4～7の幅区分、ZL8～13の通常部、ZL14以上の詳細線で形状・コードが切り替わる。河川法上の管理区分は持たない | 既定の重畳として内蔵。河川の大・中一般化線を連続ガイドとしてオーバーズームし、詳細線・水域と併記。SourceをMap間で共有 |

## 河川・観測・リアルタイム候補

| 対象 | 区分 | 公式候補・形式 | ライセンス・容量・変換判断 | Version 0.1判断 |
|---|---|---|---|---|
| 河川ライン | A（試験）＋B | 画面表示には上記試験MVTを利用可能。安定した属性付き候補は国土数値情報「河川」W05のGML／シェープファイル等 | 試験MVTは仕様変更リスクがある。W05全国一括は容量・描画負荷が大きく、[利用約款](https://nlftp.mlit.go.jp/ksj/other/agreement.html)確認、地域抽出、簡略化、GeoJSON化が必要 | 試験MVTを選択式で内蔵。W05は同梱せず、利用者のKML/GeoJSON読込みも維持 |
| 水位計・危機管理型水位計・河川監視カメラの公式画面 | 対象外（案内） | 国土交通省「川の防災情報」の公式マップは中心緯度・経度・ズームをURLで指定でき、公式画面上の施設マーカーから観測情報へ移動できる | データAPIとしては扱わず、利用者が明示的に選んだ時だけ公式画面を開く。座標・ズーム以外のアプリデータは渡さない | 「観測施設」から現在中心付近の公式マップを開く案内を実装 |
| 水位観測所位置のアプリ内表示 | B（候補） | 国土交通省の水文水質データベース等で公式地点情報を取得できる候補 | 全国地点の安定したブラウザーAPIとしては採用せず、正式な一括配布物・利用条件を再確認後に静的GeoJSON化する | 同梱しない。実値と混同しない地点メタデータ設計も必要 |
| 雨量観測所位置・アメダス | B（候補） | 国土交通省の水文水質データベース、気象庁の観測所一覧・地域気象観測所一覧等の公式地点情報候補 | 取得日、項目定義、座標精度、廃止・移設、利用条件を記録した事前変換が必要。画面HTMLの抽出はしない | 同梱しない。公式一括配布物を再監査後、出典付き静的GeoJSONを検討 |
| リアルタイム水位 | C | 「川の防災情報」の公式画面は存在するが、Version 0.1実装の根拠にできる安定した公開ブラウザーAPI仕様を確認していない | 画面HTML・内部通信の解析、スクレイピング、CORS回避プロキシが必要になる方式は禁止 | 見送り |
| リアルタイム雨量 | C | 同上 | 公開画面を機械APIと推定しない。更新間隔・欠測・再配布条件も正式仕様が必要 | 見送り |
| 雨量コンター・XRAIN | C | 国土交通省の公式閲覧サービス・配信はあるが、Version 0.1で直接採用できる恒久URL、CORS、利用条件を公開仕様として確定していない | 内部タイルURLの逆解析は行わない。公式仕様が確認できればAとして再監査する | 見送り |
| 累積雨量コンター | C | 公式画面上の表示候補 | 公開仕様・期間定義・欠測表現・二次利用条件を確認できる直接APIを採用根拠として確定していない | 見送り |

「川の防災情報」の[取り扱い上の注意](https://www.river.go.jp/kawabou/kwb_apend/html/caution.html)は、ツール等による定期的・継続的な自動収集を行わないよう案内し、継続利用には配信サービスを示している。[一般財団法人河川情報センターの水防災オープンデータ提供サービス](https://www.river.or.jp/koeki/opendata/index.html)は、水位・危機管理型水位計・河川監視カメラ等を申込制の配信対象としている。このため、公開画面の内部通信を無料APIとみなした取り込みは行わない。

## 静的河川データを将来追加する条件

出典URL、データ版・取得日、利用条件、対象地域、元座標系、変換コマンド、簡略化許容誤差、元容量と配布容量を記録する。全国データを単一GeoJSONで置かず、流域・都道府県等に分割し、必要時だけ読み込む。試験MVTは軽量な概況表示に限定する。正式版または長期安定仕様が公開された場合は再監査し、属性検索やW05との役割分担を見直す。
