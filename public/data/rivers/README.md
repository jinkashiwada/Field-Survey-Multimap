# 河川データ配置予定領域

Version 0.1は全国河川データを同梱しません。利用者は公式データから作成したEPSG:4326のKMLまたはGeoJSONを画面からローカル読込みできます。LineString／MultiLineStringは青色で表示され、`name`、`riverName`、`河川名`属性を選択時の名称候補にします。

画面の「河川中心線（試験公開）」は、このディレクトリのデータではなく国土地理院の公式試験公開ベクトルタイルを必要時だけ取得します。軽量な概況表示には使えますが、試験仕様であり、提供継続・属性完全性・更新頻度を保証しません。安定した調査用河川属性が必要な場合は、以下の地域別静的データまたはローカル読込みを使う方針です。

将来このディレクトリへ事前変換データを配置する場合は、全国単一ファイルを避け、地域・流域等で分割してください。各配布物と同じ変更に次を記録します。

- 公式出典URL、データセット名・版、取得日、利用条件
- 対象地域、元形式、元座標系、変換後座標系
- 変換・簡略化・属性選別の再現可能なコマンド
- 簡略化許容誤差、元容量、変換後容量、地物数
- 更新方法と差分確認方法

候補は国土数値情報「河川」W05ですが、採用前に最新メタデータと利用約款を再確認します。詳細は `docs/data-source-audit.md` を参照してください。
